About OnlinePGP.com

OnlinePGP.com was created with a simple goal: to make strong OpenPGP cryptography accessible to anyone with a web browser, without requiring complex command-line setups or software installations.

Who Runs OnlinePGP.com & Why It Is Client-Side

OnlinePGP.com is maintained as an open-source web utility (view the source on GitHub) built for privacy-conscious individuals, developers, journalists, and students who need a fast, zero-install way to work with PGP keys and messages.

Traditional web tools often process user input on a remote server. For cryptography, that model creates unnecessary risk: if a server receives your private key or passphrase, you have to trust that the operator never logs, leaks, or misuses it. That is why OnlinePGP.com is architected as a static website where all cryptographic operations run 100% locally in your browser.

How It Works Under the Hood

Every cryptographic operation on OnlinePGP.com—including 2048-bit RSA key pair generation, message encryption, decryption, digital signing, and signature verification—executes inside your browser's JavaScript engine using the open-source OpenPGP.js library (v4.10.10) and your browser's Web Crypto random number generator.

Your private keys, passphrases, and plaintext messages are never uploaded to our servers. At the same time, we are transparent about how the website itself operates: we use Google Analytics and Google AdSense to measure aggregate traffic and fund hosting, with Google Consent Mode v2 enabled for visitors in the EEA and UK. Read our Privacy Policy for full details.

Educational Mission

Cryptography is only effective when people understand how to use it safely. Beyond the tool itself, our PGP Blog—written and maintained by the OnlinePGP Editorial Team—provides clear, practical guides on how Pretty Good Privacy works, how to verify key fingerprints, how to configure desktop email clients, and how to avoid common security pitfalls.
