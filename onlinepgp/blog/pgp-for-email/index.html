PGP for Email: Thunderbird, Proton Mail, and Gmail

By OnlinePGP Editorial Team • Published November 23, 2026

Inline PGP vs. PGP/MIME

When using PGP with email, you will encounter two formats: inline PGP (pasting a -----BEGIN PGP MESSAGE----- block directly into the email body, which is what OnlinePGP.com produces) and PGP/MIME (a structured email format used by desktop mail clients to encrypt both the body and attachments together).

Remember that neither format hides From, To, or Date headers, and classic inline PGP never hides the Subject line.

Choosing a Setup: Browser Tool vs. Daily Mail Client

If you only need to encrypt an occasional message, OnlinePGP.com lets you encrypt and decrypt right in your browser without configuring a mail client. If you exchange encrypted emails every day, integrating OpenPGP into your email client is much more convenient.

1. Mozilla Thunderbird (Built-In OpenPGP)

Mozilla Thunderbird includes native OpenPGP support powered by the RNP library. To set it up, open Account Settings → End-to-End Encryption, where you can generate a new key or import an existing private key. Note that encryption is not fully automatic for every message by default: when composing an email, you enable encryption for that message once you have imported and accepted the recipient's public key.

2. Proton Mail

Proton Mail encrypts messages between Proton users automatically. When emailing external contacts who use standard PGP, you can import their public key in your contact settings so Proton Mail encrypts outgoing messages with OpenPGP, and you can export or import your own PGP keys as needed.

3. Gmail and Standard Webmail

Standard Gmail does not support OpenPGP natively. You have two main options: install an open-source browser extension such as Mailvelope, or encrypt your text locally using OnlinePGP.com and paste the armored block into Gmail's compose window (ideally in plain-text mode). Keep in mind that browser extensions have limited support on mobile webmail.

Apple Mail and Windows Outlook

On macOS, Apple Mail users typically rely on third-party tools such as GPG Suite. On Windows, Outlook users often use Gpg4win (which includes Kleopatra and the GpgOL plugin). Whichever client you choose, make sure you back up your private key so you do not lose access if you switch devices.

Operational Tips for Encrypted Email

Keep subject lines non-sensitive, prefer plain-text formatting when pasting inline PGP, and avoid sending encrypted messages to public mailing lists unless the list is specifically configured for it. Frequently Asked Questions

Does Gmail support PGP natively?

No. Standard Gmail has no built-in OpenPGP support, so you need a browser extension like Mailvelope or a client-side tool like OnlinePGP.com.

Does Thunderbird support PGP?

Yes. Mozilla Thunderbird includes built-in OpenPGP support under Account Settings without requiring third-party plugins.

Does Proton Mail use PGP?

Proton Mail encrypts Proton-to-Proton messages automatically and supports standard OpenPGP for external contacts when you add their public key.

Can I paste an armored PGP message into any email app?

Yes. Because inline PGP is plain ASCII text, you can paste a BEGIN PGP MESSAGE block into virtually any webmail or mobile email app.
