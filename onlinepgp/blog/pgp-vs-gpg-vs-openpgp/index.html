PGP vs GPG vs OpenPGP: What Is the Difference?

By OnlinePGP Editorial Team • Published November 23, 2026

Why People Confuse PGP, GPG, and OpenPGP

If you have ever searched for email encryption, you have probably seen the terms PGP, GPG, and OpenPGP used interchangeably. While they are closely related, they refer to three distinct things: a historical and commercial product, an open technical standard, and a free software implementation.

1. PGP (Pretty Good Privacy)

PGP was the original encryption program written by Phil Zimmermann in 1991. Over the years, PGP was commercialized and acquired by several companies—eventually becoming Symantec Encryption Desktop under Broadcom. Today, people often say 'PGP' casually to refer to any OpenPGP-compatible encryption tool.

2. OpenPGP (The Open Standard)

In 1997, the Internet Engineering Task Force (IETF) formed the OpenPGP working group to turn PGP's message and key format into an open, vendor-neutral specification. The group published RFC 2440 in 1998, updated it to RFC 4880 in 2007, and released RFC 9580 (OpenPGP v6) in July 2024.

Because OpenPGP is an open standard, anyone can build compatible software without paying licensing fees. OnlinePGP.com uses OpenPGP.js, a JavaScript implementation of this standard.

3. GPG / GnuPG (GNU Privacy Guard)

GnuPG (commonly abbreviated as GPG) is a free, open-source implementation of the OpenPGP standard maintained by the GNU Project. It is pre-installed on many Linux distributions and powers desktop bundles such as Gpg4win on Windows and GPG Suite on macOS.

Other OpenPGP Implementations Worth Knowing

Beyond GnuPG and OpenPGP.js, several other major implementations power everyday privacy tools: RNP (a C++ OpenPGP library used natively by Mozilla Thunderbird), Mailvelope (a browser extension for webmail), and Proton Mail's built-in OpenPGP engine.

Quick Comparison

  • PGP: Original 1991 software and commercial brand; proprietary in its commercial form.
  • OpenPGP: Open IETF specification (RFC 2440 / 4880 / 9580); defines how keys and messages are formatted.
  • GPG (GnuPG): Free, open-source command-line software implementing OpenPGP; ideal for desktop, scripts, and offline keys.
  • OpenPGP.js: Open-source JavaScript library implementing OpenPGP in the browser, powering OnlinePGP.com.

Compatibility and Which One to Choose

Because all of these tools implement the OpenPGP standard, keys and messages usually interoperate smoothly—especially when using widely supported algorithms like RSA-2048. One caveat to keep in mind is that very old clients may not understand modern RFC 9580 (v6) keys or newer elliptic-curve algorithms.

Frequently Asked Questions

Are PGP and GPG compatible with each other?

Yes. Both follow the OpenPGP standard, so keys and messages created in one generally work in the other when both sides support the same algorithms.

Is OpenPGP a program I can download?

No. OpenPGP is a technical specification (standard), not a piece of software.

Which one should I use?

For quick browser tasks, use OnlinePGP.com. For daily email, use Thunderbird or Proton Mail. For command-line automation or offline keys, use GnuPG (GPG).

Will a key generated on OnlinePGP.com work in GnuPG?

Yes. OnlinePGP.com generates standard v4 RSA-2048 OpenPGP keys that can be imported directly into GnuPG, Thunderbird, and Proton Mail.
