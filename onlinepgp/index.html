How It Works

Watch how it works — this is an animation, use the tool above to encrypt for real.

1. Generate Keys

Create a 2048-bit RSA key pair locally in your browser. Share your public key and keep your private key secret.

2. Encrypt & Decrypt

Lock messages with a recipient's public key so only their private key and passphrase can unlock them.

3. Sign & Verify

Prove message authorship with your private key and verify incoming signed text using the sender's public key.

Security & Privacy Transparency

All cryptographic operations (key generation, encryption, decryption, signing, and verification) run locally in your browser via OpenPGP.js. Your keys, passphrases, and messages are never transmitted to or stored on our server. You can inspect the open-source code on GitHub. Frequently Asked Questions

Are my keys or messages ever sent to a server?

No. All OpenPGP operations run locally in your browser using OpenPGP.js. Your keys, passphrases, and messages never leave your device.

What key type does OnlinePGP.com generate?

The tool generates standard OpenPGP v4 2048-bit RSA key pairs, which are widely compatible with GnuPG, Mozilla Thunderbird, and Proton Mail.

Can I use this tool offline?

Yes. Once the page and /asset/openpgp.min.js have loaded, all cryptographic functions work without an internet connection.
