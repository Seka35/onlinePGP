Base64 Encoder / Decoder

UTF-8 safe Base64 encoding and decoding for text and files, with URL-safe variant support.

What Is Base64 Encoding?

Base64 converts binary data into plain ASCII text so it can safely travel through email, JSON, URLs, and web forms. OpenPGP ASCII Armor itself uses Base64 under the hood to represent binary keys and encrypted packets.

Important: Encoding Is Not Encryption

Anyone can decode Base64 back to the original text—it provides zero confidentiality. If you need to hide sensitive data, use OnlinePGP.com or PGP File Encryption. Read What Is PGP? and Is Online PGP Safe? for more, or check Hash Generator.

Frequently Asked Questions

Is Base64 encryption?

No. Base64 is an encoding format, not encryption. Anyone can decode it.

Does this tool support emojis and accents?

Yes. It uses TextEncoder and TextDecoder for full UTF-8 support.

What is URL-safe Base64?

It replaces + and / with - and _ and strips = padding so strings can be used safely in URLs.

Are my files or text sent to a server?

No. Encoding and decoding run 100% locally in your browser.
