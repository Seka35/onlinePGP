What Is a Cryptographic Hash?

A cryptographic hash function converts any text or file into a fixed-length hexadecimal digest. Even a single-bit change in the input produces a completely different hash. SHA-256 and SHA-512 are standard for verifying software downloads, ISO images, and backups.

How to Verify a File Checksum

  1. Select your downloaded file (or paste text) and click COMPUTE HASHES.
  2. Paste the official checksum published by the software vendor into the verification box.
  3. The tool immediately confirms whether the checksum matches.

Security Notes on MD5 and SHA-1

MD5 and SHA-1 are cryptographically broken against collision attacks and should never be used for security signatures—only for legacy compatibility. For cryptographic authenticity, use SHA-256/SHA-512 or verify a PGP signature with our PGP Signature Verifier. You can also explore Base64 Encoder / Decoder, Online PGP Tool, and What Is PGP?.

Frequently Asked Questions

Are files uploaded when hashing?

No. Files are hashed locally in your browser using the Web Crypto API.

Why is MD5 marked as insecure?

MD5 is vulnerable to collision attacks and should only be used to check legacy checksums, not security.

What is the SHA-256 hash of 'abc'?

ba7816bf8f01cfea414140de5dae2223b00361a396177a9cb410ff61f20015ad.

Should I use checksums or PGP signatures?

PGP signatures prove both integrity and who signed the file; checksums only verify integrity.
