Free Online Security & Encryption Tools

Every utility below runs 100% locally in your browser using OpenPGP.js and the Web Crypto API. Your keys, files, and passwords never leave your device.

Home › Tools

OnlinePGP.com started with a single goal: making OpenPGP encryption accessible without installing command-line software. Today, the suite includes seven focused, zero-signup utilities for everyday privacy and developer workflows. Whether you need to inspect a public key's fingerprint before trusting it, encrypt a sensitive document, generate a high-entropy Diceware passphrase, or verify a software download's SHA-256 checksum, every operation executes client-side in your browser's memory.

Online PGP Tool

Generate 2048-bit RSA key pairs, encrypt, decrypt, sign, and verify text messages.

PGP Key Viewer

Inspect fingerprint, key ID, algorithm, dates, user IDs, subkeys, and revocation status.

PGP File Encryption

Encrypt or decrypt files locally using a PGP key or symmetric passphrase.

Password & Passphrase Generator

Create cryptographic random passwords and Diceware passphrases with entropy meter.

Hash & Checksum Verifier

Compute SHA-1, SHA-256, SHA-384, SHA-512, and MD5 for text or files and verify checksums.

Base64 Encoder / Decoder

UTF-8 safe Base64 encoding and decoding for text and files, with URL-safe mode.

PGP Signature Verifier

Verify detached (.asc/.sig) file signatures and clear-signed text messages.
