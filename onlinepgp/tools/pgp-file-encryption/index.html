Client-Side PGP File Encryption

While our homepage PGP tool focuses on text messages, you often need to protect binary files—such as PDFs, tax documents, archives, or backups. This tool encrypts and decrypts files directly in your browser's memory using OpenPGP.js and triggers a local download.

How to Encrypt and Decrypt Step by Step

  1. To encrypt: Choose a file, paste the recipient's public key (or enter a strong symmetric password), and click ENCRYPT & DOWNLOAD .PGP.
  2. To decrypt: Select a .pgp, .gpg, or .asc file, provide your private key and passphrase (or the symmetric password), and click DECRYPT & DOWNLOAD FILE.

Browser Memory & Security Notes

Because the entire file is read into browser memory, this tool works best for files under 50–100 MB. For multi-gigabyte archives, use desktop GnuPG. Also check Hash & Checksum Verifier to verify file integrity, or Password Generator for strong symmetric passwords. Read How to Encrypt and Decrypt a Message and Is Online PGP Safe? for more.

Frequently Asked Questions

Are my files uploaded to a server?

No. Files are read into your browser's local memory and encrypted or decrypted client-side.

What is the maximum file size?

Because processing happens in browser RAM, keep files under roughly 50–100 MB for smooth performance.

Can I decrypt files created with GnuPG?

Yes, standard OpenPGP .pgp, .gpg, and .asc files are supported.

Should I use a public key or a password?

Use a public key when sending to someone else; use a strong symmetric password for personal backups.
