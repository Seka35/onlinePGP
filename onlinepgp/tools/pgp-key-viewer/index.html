What the PGP Key Viewer Does

Before trusting a contact's public key or encrypting sensitive data, you should verify what is actually inside the key block. Our client-side PGP Key Viewer parses any ASCII-armored OpenPGP key locally in your browser using OpenPGP.js—without uploading anything to a server.

It extracts the full cryptographic fingerprint (formatted in readable 4-character groups), the long 64-bit Key ID, the public-key algorithm and bit length (such as RSA-2048, RSA-4096, or Ed25519/X25519), creation and expiration dates, attached User IDs (name and email), subkeys, and whether the key has been revoked.

How to Use It Step by Step

  1. Copy an ASCII-armored public key block (or click IMPORT KEY FILE to load a .txt or .asc file).
  2. Click INSPECT PGP KEY.
  3. Compare the displayed fingerprint with your contact over a trusted out-of-band channel, such as a voice call or Signal.

Common Use Cases & Security Notes

Use this tool to check keys you generated with our Online PGP Tool, confirm whether a key you found on a keyserver is expired or revoked, or verify a developer's signing key before using PGP Signature Verifier. Never paste a private key on an untrusted computer; if you accidentally paste a private key here, the viewer will warn you immediately.

Learn more in How to Share Your Public Key and Verify Fingerprints and What Is PGP and How Does It Work?, or explore all security tools.

Frequently Asked Questions

Does this tool upload my PGP key?

No. Key parsing runs 100% locally in your browser via OpenPGP.js.

Why does it warn if I paste a private key?

Private keys must stay secret. While this page never uploads your key, you should avoid pasting private keys unnecessarily.

What is the difference between a fingerprint and a Key ID?

A Key ID is a shorter suffix of the full fingerprint. Always verify the full fingerprint to prevent collision attacks.

Can I inspect keys generated on OnlinePGP.com?

Yes. Keys generated on the homepage tool are standard OpenPGP v4 RSA-2048 keys.
