Why Verify PGP Signatures?

When you download software, security advisories, or important announcements, a valid PGP signature proves two things: the file or text came from the holder of the matching private key, and it has not been altered since it was signed.

How to Verify a File or Message

  1. Paste the signer's public key (inspect its fingerprint first with PGP Key Viewer).
  2. Either paste a clear-signed text message, or select the downloaded file and paste its detached .asc/.sig signature.
  3. Click VERIFY SIGNATURE to see whether the signature is valid.

For creating signatures, use our Online PGP Tool. Learn more in How to Verify Fingerprints and What Is PGP?, or check Hash & Checksum Verifier.

Frequently Asked Questions

What is a detached signature?

A separate .asc or .sig file that signs a binary file without modifying the file itself.

Does verifying a signature upload my file?

No. Verification runs 100% locally in your browser using OpenPGP.js.

What if the signature is valid but I don't recognize the key?

Always verify the signer's public key fingerprint out-of-band before trusting a valid signature.

Can I also sign messages on this site?

Yes, use the Sign tab on the homepage Online PGP Tool.
